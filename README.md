# NASA Weather Analytics

Analyse de 15 ans de données météorologiques NASA POWER et prévision de la température du lendemain, avec un dashboard interactif.

## Objectif
Explorer l'évolution des variables météorologiques sur 15 ans et construire des modèles de prédiction de la température du lendemain.

## Données
- Source : NASA POWER (données météorologiques quotidiennes)
- Période : 15 ans

## Étapes du projet
1. Collecte des données NASA POWER
2. Nettoyage et préparation des données avec Python et Pandas
3. Analyse exploratoire et visualisation
4. Développement de modèles de prédiction de la température du lendemain
5. Dashboard interactif avec Streamlit et Plotly

## Technologies
Python · Pandas · Streamlit · Plotly
